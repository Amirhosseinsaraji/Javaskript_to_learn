# Calculator App

A responsive calculator built as a team project for the [Frontend Mentor calculator challenge](https://www.frontendmentor.io/challenges/calculator-app-9lteq5N29). The project uses plain HTML, CSS and JavaScript without a build step.

## Run locally

1. Clone the [repository](https://github.com/Amirhosseinsaraji/Javaskript_to_learn).
2. Open `index.html` in a browser, or serve the folder with a local development server such as Live Server.

## Features

- Add, subtract, multiply and divide; DEL removes a character and RESET clears the calculation.
- Division by zero displays an error. Long results are rounded to 10 significant digits.
- Choose one of three themes. The selection is saved in the browser; the initial choice follows the system light/dark preference when no selection is saved.
- Use the mouse or keyboard: digits, decimal point and operators; Enter calculates, Backspace deletes, and Escape resets. Use `*` for multiplication.
- Long display values can be scrolled horizontally.

## Project structure

- `index.html`: calculator markup and controls.
- `styles.css`: layout, responsive rules and theme colors.
- `script.js`: calculator behavior, theme persistence and keyboard controls.
- `style-guide.md` and `design/`: challenge colors and design references.
